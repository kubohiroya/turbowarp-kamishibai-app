# ブロックエディターの3フレーム構成

関連: [ブロックアイコンからのプレビュー・配置編集](dsl-4-block-icon-preview.md)。

場面（C形）ブロックのダイアログを、フォームだけの縦長の画面から、フォーム・場面プレビュー・コード編集の3フレームに変える。入れ子のブロックに「このブロックにフォームはありません」とだけ出る状態を無くし、どのブロックでも編集できる面を用意する。

## 画面構成

- ダイアログを2カラムにする。左カラムは従来のフォーム（入れ子ブロックのツリーと、各ブロックのJSONフォーム・固定入力フォーム）。右カラムを上下に分け、上に場面プレビュー、下に選択ブロックのブロック表示を置く。
- 右カラムの中の上下分割は紙芝居側が持つ。data-editor は右カラムの枠と選択の通知だけを提供し、枠の中身の配置には関与しない。
- 右上のプレビューは左カラムをスクロールしても保持する。
- 幅が足りない画面では縦積みにし、左カラム・プレビュー・ブロック表示の順に並べる。
- 現在の data-editor は「左=プレビュー、右=フォーム」の2カラムであり、この構成とは列の順序が逆になっている。

## 選択

- 左カラムのブロック見出しをクリックすると、そのブロックが選択になる。選択は常に1つで、右上と右下は選択に追従する。data-editor はプレビュー登録の `mount` の第4引数で選択を渡し、`get()` が選択ブロックの snapshot・そのブロック自身の編集コンテキスト・開いたブロックからの深さを返す。紙芝居側は選択が変わるたびに右カラムの中身を作り直す。
- 選択が場面ブロック自身のときは、右上で場面を冒頭から再生する。移動や待機の秒数は台本のまま使う。
- 選択が場面の中の入れ子ブロックのときは、場面の冒頭からその位置までを、待機の秒数と移動の所要時間を 0 として早送りし、そのアクションの時点の画面を表示する。音と非表示の処理も飛ばす。既存の still モードがこの再現を行う。
- その位置の動きそのものを実時間で見たいときは、再生ボタンで動作つきの再生に切り替える。人の入力や認識結果で経路が変わる位置は推測せず、理由を表示する。
- 右下は選択ブロックを Blockly のブロックとして表示し、そのブロックを編集する。フォームを持たないブロック（stage・wait・goto・hide・setLayer など）と、入れ子を持つ構造ブロックも対象にする。ブロックの描画には Editor が持つ `Scratch.gui.getBlockly()` を使い、元のワークスペースから選択ブロックの範囲を複製して表示する。元のワークスペース・ステージ・VM は書き換えない。

### 右下で編集できる範囲

- 編集できるのは引数の値だけとする。ブロックの追加・削除・並べ替えは行わない。複製したブロックは移動も削除もできない状態にし、次のブロックと入れ子は複製から外す。処理の並びは左カラムのツリーが持つ。
- 引数の値は、フォームとステージのドラッグが使う下書きへ同じ形で書き込む。固定入力の契約が編集可能とした引数だけを対象にし、JSON を持つ引数（場面の設定・せりふ・心の声）と読み取り専用の入力はフォームが持つ。その引数を右下で変えようとしたときは、元の値へ戻して理由を表示する。
- フォームやステージのドラッグで値が変わったときは、右下の表示へ反映する。どの面で変えても、保存するまで台本には反映しない。
- 数値の引数には数値として書き込み、空欄や数値にならない入力は受け取らない。保存中は編集できない。
- フォーム・コード編集・プレビューは同じ編集セッションを使う。どの面での変更も保存するまで台本とステージに反映しない。保存・取消・検証・undoは既存のダイアログが引き続き所有する。

## ステージ上の直接編集

- `show actor` と `move actor` を選択しているとき、右上のアクターをドラッグすると X・Y の引数が同期する。引数を手入力したときは、再生し直す前にその位置をステージへ反映する。
- アクターを右クリックすると「拡大縮小」「回転」の項目を持つメニューを出す。「回転」は下位メニューを持ち、「自由に回転」「左右のみ」「回転しない」から選ぶ。どちらの項目も、そのブロックに書き込める引数が無いときは選べない状態にし、理由を表示する。
- 「拡大縮小」を選ぶと、大きさのスライダーとリセット・キャンセル・保存のボタンを出す。パネルを開いている間はアクターのどこをドラッグしても拡大縮小になり、スライダーと表示が追従する。開いた時点で再生を止め、値は保存を押すまで引数に書き込まない。キャンセルは開いた時点の値へ戻し、リセットはそのブロックの引数の既定値（`show actor` は 100%）へ戻す。保存はダイアログの下書きへ書き込み、台本へはダイアログの保存で反映する。
- 拡大縮小は `show actor` と `set actor skin` の SCALE へ書き込む。`move actor` は大きさの引数を持たないため、メニューを開いた時点で項目を選べない状態にし、直前の `show actor` か `set actor skin` で設定する旨を表示する。
- 回転は `show actor` の引数として持つ。`rotation` が回転方法（`allAround`・`leftRight`・`none`）、`direction` が向きの角度で、どちらも省略できる。省略した場合はアクターの現在の回転に触れない。既存の台本と、この引数より前に保存された SB3 のブロックは、どちらも値を持たないまま有効とする。
- 下位メニューで回転方法を選ぶと、その方法をプレビューへすぐ適用し、角度のスライダーを開く。「回転しない」では角度を変えられない状態にする。アクターのドラッグは、その中心から見た向きとして角度に変わる。保存は回転方法と角度の両方を引数へ書き込み、キャンセルは開いた時点の回転方法と角度へ戻す。リセットは向き 90 度（右向き）へ戻す。
- 角度は Scratch と同じ −179 度から 180 度の範囲に収める。90 度が右向きで、0 度が上向きになる。

## 所有者と作業分担

- DSL: `show actor` の `rotation`・`direction`（`schema/dsl-4.schema.json` の `showArgs` と `rotationStyle`）。ブロックの引数は `ROTATION`・`DIRECTION`、再生時は俳優のポートとアダプタが Scratch の回転方法と向きへ渡す。
- app（このリポジトリ）: 右カラムの中身すべて。場面プレビューと再生、ステージのジェスチャー（ドラッグ・右クリックメニュー・スライダー）、選択ブロックのブロック表示と編集。実装は `src/dsl4/platform/block-icon-preview-editor.ts`（上下の組み立てとプレビュー）と `src/dsl4/platform/block-icon-block-view.ts`（ブロック表示と引数の読み書き）。
- data-editor: 左カラムのフォームとツリー、右カラムの枠、選択の通知。0.11.4 でフォームが左・プレビューが右になり、続く版で `mount` の第4引数として選択を渡す。入れ子のブロックが自分のフォームを持つ場合、そのブロック用のプレビューは合成せず、ダイアログが持つ1つのペインが受け持つ。
- scratch-gui: data-editor の対応版を取り込み、新しい表示文字列を渡す。

配布中の Editor は data-editor 0.5.0 を使い `registerPreview` を持たないため、プレビューもコード編集も装着されない。3フレームを利用するには、data-editor の対応版を組み込んだ Editor の配布が必要になる。

## 導入と切戻し

プレビューの有効・無効は `src/dsl4/block-icon-preview-feature-flags.ts` が起動時に一度だけ読む。既定 ON で、起動 URL の `twPlusBlockPreview=0` か読み込み前の `globalThis.TW_BLOCK_ICON_PREVIEWS = false` で切り戻す。未対応の Editor では従来のフォームだけが開く。

回帰確認では、場面ブロックを開いて左にフォーム・右上に場面の再生・右下に選択ブロックのブロック表示が出ることを確認する。入れ子のブロックを選び、待機と移動を 0 とした早送りでその位置の画面が出ること、フォームを持たないブロックでも右下で編集して保存できることを確認する。`show actor` を選んでドラッグと手入力の双方向、右クリックからの拡大縮小を確認する。`twPlusBlockPreview=0` で開き直し、フォームだけが開くことを確認する。
