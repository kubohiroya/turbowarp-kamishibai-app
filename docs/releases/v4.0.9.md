# 4.0.9 — カメラ映像の置き場所と濃さを台本から決める

4.0.9 は、ポーズ認識中に見えるカメラ映像（preview）の置き場所と濃さを台本から指定できるようにしました。台本の他の書き方、保存データ、作品の保存形式、ブロックは変わりません。

## 画面全体に薄く重ねる固定値をやめる

4.0.8 までのカメラ映像は、台本に何を書いても DSL 3.2 と同じ「画面全体・不透明度 0.2」で固定でした。場面の絵が明るい部屋では、ポーズ認識中でも映像がほとんど見えず、カメラが写っているかどうかを観客も演者も確かめられませんでした。

4.0.9 では `recognition.preview` に次の 2 つを書けます。

```yaml
recognition:
  preview:
    mirroring: mirrored
    position: bottom-right
    opacity: 0.8
```

- `position`: `full-stage` | `top-left` | `top-right` | `bottom-left` | `bottom-right` | `center`。省略時は `full-stage`。
- `opacity`: 0 以上 1 以下の数値。省略時は 0.2。

どちらも作品全体の設定です。カメラを用意するときと、`pose`・`poseInputToChangeScene`・`imageInputToChangeScene` が映像を見せるたびに同じ値を適用するため、場面をまたいでも置き場所が変わりません。

### 変わらないもの

- 省略した台本の見え方は 4.0.8 までと同じです（画面全体・不透明度 0.2）。
- 映像を見せるのは、これまでどおりポーズ認識を待っている間だけです。語りの場面では隠します。
- 表示だけの設定です。認識へ渡す映像、認識度、ポーズの成立判定は変わりません。
- `mirroring` と `overlay` の書き方と既定値は変わりません。場面ごとの上書きは `posePreview.mirroring` だけで、置き場所と濃さには場面単位の上書きがありません。
- 範囲外の値（`position: top-center`、`opacity: 1.5` など）は schema が台本の誤りとして拒否します。

## 切り戻し

4.0.8 の npm パッケージ、Standard SB3、Player に戻してください。`position` と `opacity` を書いた台本は、4.0.8 では schema の誤りになるため、その 2 行を外してください。台本や保存データの変換は不要です。
