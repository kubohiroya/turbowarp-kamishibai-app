# 4.0.0-rc.93 — エディタでの台本の一時停止と、デバッガーの Logs タブへの出力

rc.92 は凍結しましたが公開していません。この版は rc.91 からの変更として、rc.92 の変更と次の変更を含みます。

## 変更範囲

### エディタでの台本の一時停止（rc.92 の変更）

エディタ（TurboWarp-Plus-Editor など）で埋め込み作品を実行すると、台本の `debugger` アクション（実行ランタイム拡張の `debugger` ブロック）の直前で台本の実行が止まり、TurboWarp のデバッガーが作品を一時停止してウィンドウを開きます。止まった場面とアクション番号、その時点の台本の変数は、デバッガーの「ログ」タブに書き出されます。デバッガーで再開すると台本も続きから進みます。

authoring build の runtime 拡張は `getInspectorVariables()` を持ち、TurboWarp-Plus-Editor の変数ペイン（`@kubohiroya/turbowarp-plus-editor-sprite-panes` の対応版）が、一時停止中の台本の変数を「台本の変数」の表として表示できます。

配布用の playback runtime・packager・Web Player では、`debugger` は従来どおり何もせずに次へ進みます。デバッガーのアドオンが無いか停止できない場合も、止まらずに進みます。新しい起動時 flag `dsl4EditorDebugger` は、エディタ上の authoring runtime だけが ON にします。

あわせて、依存の `scratch-vm`・`scratch-audio`・`scratch-render`・`scratch-render-fonts` の取得元を、同じコミットのまま kubohiroya のフォークに替えました。生成物は変わりません。

### 警告とエラーをデバッガーの Logs タブにも出す

デバッガーアドオンが有効なエディターでは、ランタイムの警告とエラーがデバッガーの Logs タブにも出るようになりました。他の機能拡張の行や、作品のログブロックの行と並びます。Logs タブは内容を書き出せるため、URL のクエリー、ローカルのパス、資格情報は伏せて出します。コンソールへの出力はこれまでと同じです。カメラの許可を取り消したときは、警告ではなく通常の行になります。あわせて `@kubohiroya/turbowarp-runtime-adapter` を 0.6.0 に上げました。

## 切り戻し

前回の公開版 `4.0.0-rc.91` の npm パッケージ、Standard SB3、Player を使用してください。台本の DSL と保存形式は変わりません。
