# 4.0.13 — 場面のダイアログにプレビューとブロック表示を並べ、大きさと回転をステージで決める

4.0.13 では、エディターで場面のブロックを開いたときの画面を three-pane にし、ステージ上の操作から大きさと回転を設定できるようにしました。`show actor` に回転方法と向きの引数が増えますが、どちらも省略でき、省略した作品の再生は変わりません。保存データと作品の保存形式は変わりません。

## 場面のダイアログを三つの面にする

場面（C形）ブロックのダイアログは、これまで設定のフォームだけの縦長の画面でした。入れ子のブロックには「このブロックにフォームはありません。内側のブロックは編集対象に含まれます。」とだけ出て、そのブロックを編集する面がありませんでした。

4.0.13 では、左に従来のフォームと入れ子ブロックの一覧、右上に場面プレビュー、右下に選んだブロックのブロック表示を並べます。

- 左の一覧でブロックを選ぶと、右上と右下がそのブロックに追従します。場面ブロック自身を選ぶと場面を冒頭から再生し、入れ子の動作ブロックを選ぶと、待機の秒数と移動の所要時間を 0 として早送りし、そのアクションの時点の画面を表示します。動きそのものを実時間で見たいときは再生ボタンで切り替えます。
- 右下は選んだブロックを Blockly のブロックとして表示し、引数の値を直せます。`stage`・`wait`・`goto`・`hide`・`setLayer` のようにフォームを持たないブロックも対象です。ブロックの追加・削除・並べ替えはしません。JSON を持つ引数（場面の設定・せりふ・心の声）と読み取り専用の入力はフォームが持ちます。
- どの面で変えても、保存するまで台本には反映しません。

## ステージのアクターから大きさと回転を決める

右上のプレビューでアクターを右クリックすると、「拡大縮小」と「回転」を選べます。

- 「拡大縮小」はドラッグとスライダーで大きさを変え、リセット・キャンセル・保存で確定します。保存は `show actor` と `set actor skin` の大きさの引数へ書き込みます。`move actor` は大きさの引数を持たないため、項目を選べない状態にして直前の `show actor` で設定するよう案内します。
- 「回転」は下位メニューの「自由に回転」「左右のみ」「回転しない」から選び、続いて向きの角度を決めます。アクターのドラッグは、その中心から見た向きとして角度に変わります。角度は Scratch と同じ −179 度から 180 度の範囲で、90 度が右向きです。
- どちらも保存を押すまで引数に書き込まず、キャンセルは開いた時点へ戻します。台本への反映はダイアログの保存です。

## `show actor` の回転方法と向き

`show actor` に、回転方法 `rotation`（`allAround`・`leftRight`・`none`）と向き `direction`（度）を足しました。どちらも省略でき、省略した場合はアクターの回転に触れません。これらの引数より前に保存された SB3 のブロックと、既存の台本はそのまま有効です。空欄のときは台本へも書き出しません。

```yaml
- show:
    target: Hero
    skin: HeroIdle
    x: 0
    y: 0
    scale: 100
    rotation: leftRight
    direction: -90
```

## 必要な Editor

プレビューとブロック表示は、プレビュー登録 API を持つ TurboWarp Plus Editor で動きます。未対応の Editor では従来のフォームだけが開きます。既定で有効で、起動 URL に `twPlusBlockPreview=0` を付けるか、読み込み前に `globalThis.TW_BLOCK_ICON_PREVIEWS = false` を設定すると切り戻せます。

## 切り戻し

4.0.12 の npm パッケージ、Standard SB3、Player に戻してください。台本や保存データの変換は不要です。4.0.13 で `rotation` と `direction` を書いた台本は、4.0.12 では未知の項目として拒否されるため、その 2 項目を外してください。
