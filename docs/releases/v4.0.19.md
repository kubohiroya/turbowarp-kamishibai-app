# 4.0.19 — 人物アニメーションと舞台演出を既定で有効化

[4.0.16](v4.0.16.md)の人物アニメーションと舞台演出を、標準の編集・再生・配布とローカルプレビューで利用できます。
DSL宣言は `kamishibai: '4.0'` のままです。旧プレビューオプションの指定は不要です。
`animate` または `presentationEffect` を使う作品には対応ランタイムが必要です。
既存のアクションや作品は書き換えません。[演出の仕様](../design/dsl-4-presentation-effects.md)を参照してください。

未公開[4.0.17](v4.0.17.md)の無効区間専用モデルの先読み抑止も引き継ぎます。
4.0.15までの公開物と、4.0.16・4.0.17の凍結済み記録は上書きしません。
