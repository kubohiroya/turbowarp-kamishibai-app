# 4.0.29 — Standard の作品で台本ブロックの編集フォームを出す

- 4.0.25 から 4.0.28 では、Standard の作品（runtime を bundle に入れた作品）で台本ブロックの編集フォームが1つも登録されていませんでした。bundle は中の runtime からのフォーム登録を runtime 自身の拡張 ID に限って受け付けますが、runtime が bundle の名前空間でも登録しようとしたため断られ、失敗時に全部の登録を取り消していました。
- フォームは runtime 自身の名前空間だけで登録するようにしました。bundle の中では bundle が書き換え、runtime 単体ではそのまま使われます。行の表のような独自エディターは、従来どおり両方の名前空間で登録します。
- 登録は1件ずつ独立させ、1件が断られてもほかの登録を取り消さないようにしました。
- TurboWarp Plus Editor で 4.0.28 の作品を開いて確かめたときに見つかりました。経緯は [ブロックパレットの統合](../design/dsl-4-block-palette-unification.md) の §14 を参照してください。

## 互換性

再生時の動作は変わりません。4.0.28 までに作った SB3 は、それぞれに同梱されたランタイムで従来どおり動きます。
