# 4.0.24 — 組み込みYAMLの参照を矢印で示せるようにする

- ランタイム拡張のブロック定義に、エディター向けの参照の宣言（`scriptRelations`）を加えました。「組み込みYAMLの起点」と「組み込みYAMLを取り込む」は、同じ文書を指す「組み込みYAML」ハットを参照します。TurboWarp Plus Editor（Code Views の対応版以降）は、これをほかの矢印と色・太さ・線種で区別された参照の矢印として描きます。
- 宣言は opcode ではなく名前のチャンネル（`kubohiroya.kamishibai4.embeddedYamlDocument`）で結ぶため、バンドル版とバンドルしない版のどちらでも同じように働きます。

## 互換性

宣言はエディターだけが読む情報で、TurboWarp と再生時の動作は変わりません。対応していないエディターでは何も表示されません。4.0.23 までに作った SB3 は、それぞれに同梱されたランタイムで従来どおり動きます。

## 受け入れ基準と切り戻し

凍結 SB3 の再ビルドによる照合とリリース検証が通過してから公開します。旧版を使用する場合は npm で `4.0.23` を明示します。
