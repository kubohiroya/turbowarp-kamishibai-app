# 4.0.2 — 起動時のスキーマのコンパイルを遅らせる

## 変更範囲

紙芝居ランタイムは、起動のたびに台本 YAML を読む部品（source frontend）と、台本ブロックの引数を検証する部品を作っていました。どちらも作るときに DSL 4.0 の JSON Schema をコンパイルします。手元の計測（Node 26、Apple Silicon）では、前者が約 120 ms、後者が約 80 ms かかっていました。

4.0.2 では、どちらも最初に使うときに作ります（Issue #1162）。次の場面では、もうこのコストがかかりません。

- タイトル画面の表示まで
- compiled 配布の作品（台本 YAML を読まない）
- 台本の無いプロジェクト

source の作品は、最初に台本を読むときに同じコストがかかります。台本ブロックの検証部品は、台本ブロックを初めて実行するときに作ります。台本の読み取り結果、診断、作品ファイルの形式は変わりません。

## 切り戻し

4.0.1 の npm パッケージ、Standard SB3、Player に戻してください。台本や保存データの変換は不要です。
