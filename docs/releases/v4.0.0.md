# 4.0.0 正式版

4.0 RC系列を正式版へ移行します。npmの公開先は`latest`、GitHub Releaseは通常リリースです。公開を照合した4.0のSB3とPlayerをダウンロードページに掲載します。3.1／3.2の既存配布物は保持します。

family依存を検証済みの公開版へ更新し、組み込み拡張の版、lockfile、artifact fingerprint、固定SB3のsource identityとハッシュを揃えます。RCの公開履歴は変更しません。

公開前に`pnpm verify:release`で型・lint・全テスト・Chromium統合・配布物の再現性・package smokeを確認します。凍結したSB3はRelease workflowでも再構築し、同じバイト列であることを検証してから公開します。

未公開差分の切戻しはrevertで行います。公開後は同じ版やタグを上書きせず、次のpatch版で修正します。既存の3.1／3.2作品は3.2.3を引き続き利用できます。
