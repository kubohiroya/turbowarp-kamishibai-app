# 4.0.17 — 無効区間だけの認識モデルを先読みしない

`invalidate: {condition: false, then: ...}`内だけで使うモデルを、シーンのバックグラウンド取得と次シーンの先読みから除外します（#1200）。モデル宣言と無効本体は編集用に保持します。有効なポーズ・画像入力や別シーンで共有するモデルは必要時に準備し、旧台本の宣言だけの先読みと明示呼び出し時のオンデマンド取得は維持します。

DSLの系列とYAML書式は4.0のままです。変換器が派生した実行用情報を記録し、ランタイム依存収集がそれを参照します。compiled配布でも情報を保持・検証します。単一文書とinclude graphのブロックauthoring、source／compiledビルドは`invalidate-model-preload-v1`対応runtimeを要求し、不適合なら`K4-INVALIDATE-PRELOAD-RUNTIME-001`で拒否します。詳細は[専用無効化区間](../dsl4-invalidate.md)を参照してください。

未公開[4.0.16の人物アニメーションと舞台演出](v4.0.16.md)も含み、試験機能の既定OFFを維持します。4.0.16の凍結記録は変更しません。

4.0.17候補の凍結・全検証・CI結果はIssue #1200へ記録します。公開後の実物検証とは区別します。
