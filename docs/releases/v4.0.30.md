# 4.0.30 — 紙芝居のブロックグループを最初からすべて表示し、数値の入力を Scratch の形で書く

- 配布用 SB3 を TurboWarp Plus Editor で開いたとき、紙芝居のブロックグループをすべて表示するようにしました。表示の設定が保存されていない場合、Editor はスプライトやステージで既に使われているグループだけを表示するため、新しい作品では「舞台」「音」「ポーズ」など大半のグループが隠れていました。SB3 に Editor の画面状態（`tw-plus/workspace.json`）を入れ、ステージで Scratch の標準のグループと「紙芝居」の全グループを表示します。Scratch と TurboWarp はこの画面状態を無視します。設定は Editor の「ブロックグループの表示・非表示の設定」でいつでも変えられ、その結果は作品に保存されます。
- 台本ブロックを書き出すとき、数値の入力を文字列として保存するようにしました。これまでは `wait: 1` などの数値をそのまま数値で保存していたため、Editor が作品を開くたびに `vm error Unexpected input recieved in replaceUnsafeChars` をコンソールに出していました。Scratch はブロックの入力値を文字列で持ちます。読み戻した台本では、これまでどおり数値は数値になります。

## 互換性

- 以前に作った作品はそのまま開けます。数値の入力が数値で保存された作品も、これまでどおり読めます。
- 4.0.29 以前の SB3 を土台にした作品には表示の設定が入っていません。Editor の「ブロックグループの表示・非表示の設定」でグループを選んでください。
