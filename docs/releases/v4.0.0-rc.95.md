# 4.0.0-rc.95 — ブロックパレットのグループと日英表示

## 変更範囲

TurboWarp Plus では、台本ブロックと DSL 4.0 ランタイムのブロックが用途別のグループに分かれます。グループごとのアイコンと色で目的のブロックを探せます。束ねた機能拡張は、メンバーごとのグループに分かれ、それぞれの色で表示されます。

ブロックの文言とメニューの表示名はエディターの表示言語に合わせて日本語または英語になります。標準の TurboWarp と Scratch では、従来の単一カテゴリで表示されます。オペコード、引数名、メニューの値は従来どおりで、既存作品はそのまま使えます。

rc.94 の npm パッケージ、Standard SB3、Player に戻してください。既存の台本や保存データの変換は不要です。
