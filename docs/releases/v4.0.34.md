# 4.0.34 — 巻き戻しのキーで現在のactionとシーンの冒頭へ戻る

- `history.previousAction`（例：左矢印キー）は、実行中のactionがあればそのactionの開始前へ戻します。巻き戻しでactionの開始位置に止まっているときや、実行中のactionが無いときは、一つ前に完了したactionの開始前へ戻します。これまでは実行中のactionを飛ばして、一つ前に完了したactionへ戻っていました。
- `history.previousScene`（例：上矢印キー）は、シーンの途中にいれば現在のシーンの冒頭へ戻します。巻き戻しでシーンの冒頭に止まっているときは、一つ前のシーン訪問の冒頭へ戻します。これまでは常に一つ前のシーンへ戻っていました。
- `history.nextScene` と `navigation.nextAction` の動作は変わりません。
- 詳しくは [DSL 4.0 surface の環境別keymap](../design/dsl-4-surface.md) を参照してください。

## 互換性

台本の書式とキーマップの宣言は変わりません。セーブデータの形式（SaveDataV1）も変わりません。巻き戻しのキーを割り当てた作品では、キーを押したときの戻り先が上記のとおり変わります。4.0.33 までに作った SB3 は、それぞれに同梱されたランタイムで従来どおり動きます。
