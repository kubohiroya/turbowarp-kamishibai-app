# 4.0.0-rc.88 — pose stepsのC型ブロックとTurboWarp Plus依存の更新

DSLの形式は4.0です。台本の形式は変わりません。

## 変更範囲

### ブロックでの編集

- `Actor.pose: {steps}` を、編集用SB3では `recognize actor [TARGET] pose steps` のC型ブロックとして表示します。内側には、1ステップごとに `pose [POSE] skin [SKIN] sound [SOUND]` のブロックを並べます。
- skin・soundを空欄にしたステップは、YAMLへ書き出すときにその項目を省きます。
- 中身のないC型ブロックと、C型ブロックの外に置いたステップブロックは、ブロックIDを付けたエラーにします。
- `stableId` を持つposeは、これまでどおりJSONの `pose steps [STEPS]` ブロックで表示します。

## 切り戻し

前回公開版の固定依存と、対応するSB3・Playerを使用してください。rc.88の編集用SB3で保存したpose stepsのC型ブロックは、rc.87の編集用SB3では読み込めません。台本YAMLは形式が同じため、rc.87でもそのまま使えます。既存の作品SB3は個別に保管してください。
