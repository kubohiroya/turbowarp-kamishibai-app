# 4.0.0-rc.89 — タイトル画面のボタンとレイアウトの整理

DSLの形式は4.0です。台本の形式は変わりません。

## 変更範囲

### タイトル画面

- 中央のボタンを「紙芝居を始める」と「公式Webサイトを開く」の2つに分け、左右に並べました。
- 「紙芝居を始める」は大きめの緑のボタンです。押すと、右上の「×」と同じくタイトルを閉じて始めます。
- 「公式Webサイトを開く」は小さめの薄い緑のボタンにし、アイコンも小さくしました。
- 大学名と氏名を最下部の1行にまとめ、区切り線を入れて、ライセンス文との間隔を整えました。

## 切り戻し

前回公開版の固定依存と、対応するSB3・Playerを使用してください。台本YAMLと保存形式は変わらないため、rc.88でもそのまま使えます。既存の作品SB3は個別に保管してください。

公開前の候補です。
