# 4.0.37 — 再生用メニューで「もう一度」を中央に置く

- 「台本を開く」が出ない再生用のアプリでは、メニューが「もう一度」「アプリ情報」「言語」の3つになります。これまでは「もう一度」が上の行の右側に寄り、左側が空いていました。この場合は「もう一度」を上の行の水平中央に置きます。
- 「アプリ情報」と「言語」の位置、「台本を開く」が出る編集用アプリのメニュー、配布用SB3を作るボタンが出るときの配置は変わりません。
- 4.0.36までのアニメーション指定のフォーム編集・ブロックグループの統合・巻き戻しのキー・吹き出し・セーブ・ブロック編集・パレットの変更を引き継ぎます。

## 互換性

台本の書式、キーマップの宣言、セーブデータの形式（SaveDataV1）は変わりません。4.0.36 までに作った SB3 は、それぞれに同梱されたランタイムで従来どおり動きます。

## 受け入れ基準と切り戻し

凍結 SB3 の再ビルドによる照合、リリース検証、配布用 CLI の動作確認が通過してから公開します。
旧版を使用する場合は npm で `4.0.36` を明示します。
