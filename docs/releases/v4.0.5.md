# 4.0.5 — 公開の区切りに分けた作品でも、認識モデルを裏で読み込む

4.0.4 では、認識モデルを場面ごとに裏で読み込み、認識を始める時点で終わっていない場合だけ待つようにしました。ただし、台本を公開の区切りに分けた作品（publication segments）は別の読み込み部品を使っていたため、場面に入る時点で認識モデルの読み込みが終わるまで待っていました。4.0.5 では、こちらも同じ扱いにしました（Issue #1162）。

- 場面に入ると、その場面の認識モデルを裏で読み込み始めます。場面の表示やセリフは読み込みを待たずに進みます。
- ポーズ認識や画像認識を始める時点で読み込みが終わっていない場合だけ、終わるまで待ちます。失敗した場合は、その認識の時点でエラー（`K4-ASSET-PREPARE-001`）になります。
- 次の場面に入ったときに、まだ終わっていない読み込みのうち次の場面が使わないものを中止します。読み込み終えたモデルは、次の場面が確定した時点で、その場面が使わなければ解放します。
- `assets.background.*` のイベントは 4.0.4 と同じです。

### 変わらないもの

- 認識モデル以外のアセットの読み込み方、台本、診断、作品の保存形式は変わりません。
- 公開の区切りに分けていない作品の動きは 4.0.4 と同じです。

## 切り戻し

4.0.4 の npm パッケージ、Standard SB3、Player に戻してください。台本や保存データの変換は不要です。

未公開です。
