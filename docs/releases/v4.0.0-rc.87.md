# 4.0.0-rc.87 — TurboWarp Plus依存の更新

[Issue #1140](https://github.com/kubohiroya/turbowarp-kamishibai-app/issues/1140) の依存更新です。DSLの形式は4.0です。

## 変更範囲

- `@kubohiroya/turbowarp-asset-cache` を `^0.6.1` から `^0.7.0` へ更新。
- `@kubohiroya/turbowarp-async-input` を `^0.11.0` から `^0.12.0` へ更新。
- `@kubohiroya/turbowarp-bubble` を `^0.16.0` から `^0.17.0` へ更新。
- `@kubohiroya/turbowarp-camera-source` を `^0.22.1` から `^0.23.0` へ更新。
- `@kubohiroya/turbowarp-document-data` を `0.6.0-rc.0` から `0.6.0-rc.1` へ更新。
- `@kubohiroya/turbowarp-kvs` を `^0.5.1` から `^0.6.0` へ更新。
- `@kubohiroya/turbowarp-runtime-expression` を `^0.9.0` から `^0.10.0` へ更新。
- `@kubohiroya/turbowarp-svg-text` を `^0.13.0` から `^0.14.0` へ更新。
- `@kubohiroya/turbowarp-teachable-machine` を `^4.1.0` から `^4.2.0` へ更新。
- `@kubohiroya/turbowarp-yaml-json` を `0.9.0-rc.0` から `0.9.0-rc.1` へ更新。
- `@kubohiroya/sb3-toolchain` を `^0.20.0` から `^0.21.0` へ更新。
- Asset Cache と Document Data の共通 peer として `@kubohiroya/turbowarp-named-data` を `0.8.0-rc.1` に固定。

公開済みrc.79以降にmainへ入った台本の4種類の参照元、remote素材の保持コピー、Assetブロックの素材・認識モデルプレビュー、SIMD版WASMの同梱とJavaScript CPUへの切替を含みます。詳細はrc.80〜rc.86のリリースノートを参照してください。
