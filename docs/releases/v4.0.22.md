# 4.0.22 — 作品の設定に沿って SB3 を保存

- `save-sb3-format --use-project-format` で、作品に記録された標準・Plus の選択を使用できます。標準は検証済みの拡張を SB3 に同梱します。Plus は取得先と SHA-256 を確認して保存します。検証に失敗した場合は既存の出力が保持されます。明示した `--extensions` が優先されます。#1207、#1114
- リモート形式の拡張を標準 TurboWarp から読み込むための互換キャリアを明示的に選べます。初回読み込みにはネットワークが必要です。キャリアを使う対象は `--remote-compatibility-carriers` で指定します。#1204
- SB3 Writer の依存を npm の `0.5.3` に固定しました。#1205

## 受け入れ基準と切り戻し

凍結 SB3 の再ビルドによる照合、リリース検証、配布用 CLI の動作確認が通過してから公開します。
従来の保存指定を使う場合は `--use-project-format` を外します。旧版を使用する場合は npm で `4.0.21` を明示します。
