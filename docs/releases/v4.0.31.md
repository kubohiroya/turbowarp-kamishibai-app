# 4.0.31 — 台詞・効果音・ポーズの後でもセーブできるようにする

- セーブポイントは、実行の履歴に `say`・`think`・`sound`・`pose` などを1つでも持つと、復元だけでなくセーブの作成も拒否していました。対応する復元 handler を持つ port が無いため、ほとんどの作品でセーブができませんでした。
- `say`・`think`・`sound` と、段に `sound` を持たない `pose` は、action の終了とともに作用が消えます。セーブ中に実行していれば取り消して再実行するか（`say`・`think`・`pose`）、終了を待ちます（`sound`）。残る作用が無いので、拒否の対象から外しました。
- action の後も作用が残り、セーブに入らないものは引き続き拒否します。BGM（`bgm`、段に `sound` を持つ `pose`）、場面の音声（`audio`・`audioControl`）、`setText`、コスチュームの `loop`、`broadcastMessageAndWait`、custom action です。これらの保存・復元は #1160 の後続で扱います。
- 詳しくは [セーブと viewport](../design/dsl-4-save-viewport.md) を参照してください。

## 互換性

再生時の動作は変わりません。セーブデータの形式（SaveDataV1）も変わりません。4.0.30 までに作った SB3 は、それぞれに同梱されたランタイムで従来どおり動きます。
