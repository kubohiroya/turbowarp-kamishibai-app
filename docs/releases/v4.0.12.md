# 4.0.12 — 台本に入れられないブロックのエラーで、接続を確かめるよう案内する

4.0.12 では、台本のエラー画面の案内を一つ直しました。台本の書き方、保存データ、作品の保存形式、ブロック、再生の動作は変わりません。

## 台本に入れられないブロックや接続のエラーの案内を直す

台本のブロックに、台本として読めないブロックや接続が含まれていると、`K4-BLOCK-SOURCE-GRAPH-001` のエラーになります。たとえば、台本に「もし」のブロックをつないだ場合です。

4.0.6 で、台本のエラーに具体的な修正方法を示すようにしました（#1174）。このとき、`K4-BLOCK-SOURCE-GRAPH-001` を「台本ブロックが指しているファイル名か見出しを解決できませんでした」という系統に入れていました。そのため、ブロックのつなぎ方の誤りなのに、ファイル名と台本の名前を見比べるよう案内していました。

4.0.12 では、このエラーを「台本として読み取れないブロックまたは接続が含まれています」として扱い、該当ブロックと接続を確かめ、台本用の対応ブロックを使うよう案内します。ファイル名や見出しを解決できない場合（`MISSING`・`PATH`・`LABEL`・`PROJECT`・`FRAGMENT`）の案内は変わりません。

この誤りは、turbowarp-kamishibai-samples の公開前の確認（TurboWarp Plus Editor で台本ブロックに「もし」をつなぎ、エラー画面の案内を確かめる検査）で見つかりました。4.0.10 以降、この検査が通らず、Samples の公開が止まっていました。

## 切り戻し

4.0.11 の npm パッケージ、Standard SB3、Player に戻してください。台本や保存データの変換は不要です。4.0.11 に戻すと、上のエラーでファイル名と見出しを確かめるよう案内する表示に戻ります。
