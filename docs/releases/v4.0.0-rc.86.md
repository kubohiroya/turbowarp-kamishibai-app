# 4.0.0-rc.86 — Asset ブロックの認識モデルプレビュー

関連する変更は [Issue #1139](https://github.com/kubohiroya/turbowarp-kamishibai-app/issues/1139) にまとめる。前候補版の変更は [rc.85](v4.0.0-rc.85.md) を参照。

- TurboWarp Plus Editor で Asset ブロックのアイコンを開くと、JSON Schema の編集フォームと Teachable Machine のプレビューが同じダイアログに表示される。
- Image と Pose はカメラ、Audio はマイクを開始ボタンで有効にする。Pose は映像に骨格を重ね、Audio はスペクトログラムを描画する。入力の直下にクラス別の確率を表示する。
- 素材を変更するかダイアログを閉じると、プレビュー用のデバイスとモデルを解放する。

プレビューを止めるには、Editor の URL に `twPlusBlockPreview=0` を指定して再読み込みする。モデルプレビューの差分を切り戻す場合は、変更を revert して新しい候補版を生成する。
