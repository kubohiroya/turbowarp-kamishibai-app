# 4.0.1 — 再生設定画面

## 変更範囲

作品を再生する人が変えられる設定を、一つの画面にまとめました（Issue #1149）。タイトルの「設定 / Config」と、再生中の Esc で開きます。再生中に開くと action の切れ目で物語を止め、閉じるとその action の最初から再開します。

画面には、その作品で効く設定だけが出ます。

- ポーズ待ちのスキップ: 台本の `allowSkip` を初期値に、許可・禁止を上書きできます。上書きはその作品の再生中だけ有効で、保存しません。
- BGM と効果音: それぞれオン／オフと音量を変えられます。台本が指定した音量に係数を掛けるので、鳴っている音にもすぐ反映します。設定は端末に保存します。
- カメラと Teachable Machine の計算方式: 既存の設定パネルを開きます。

Player と Packager では、常に表示されていた「Tools」の Dock を隠しました。Editor ではツールバーのボタンも従来どおり使えます。台本の DSL と作品ファイルの形式は変わりません。

設計は `docs/design/dsl-4-playback-settings.md` を参照してください。

## 既知の制限

- フォルダーから開いた台本の Web プレビューでは、Esc で設定画面は開きません。
- 台本が Esc を独自に割り当てていても、再生中の Esc は設定画面を開きます。

## 切り戻し

4.0.0 の npm パッケージ、Standard SB3、Player に戻してください。台本や保存データの変換は不要です。保存済みの音量設定は残りますが、4.0.0 はそれを読みません。
