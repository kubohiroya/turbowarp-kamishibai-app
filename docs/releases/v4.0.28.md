# 4.0.28 — playback runtime でも台本ブロックの編集フォームを出す

- 台本ブロックの編集フォーム（素材などの JSON 入力、シーンの設定、ポーズの手順、セリフ、条件・行の表）を、playback runtime でも登録するようにしました。4.0.25 から 4.0.27 では authoring runtime だけが登録していたため、playback runtime を積んだ作品を Editor で開くとフォームが出ませんでした。`migrate-block-palette` が古い runtime を playback runtime に差し替えた作品も同じでした。
- Packager や Web Player のように Editor の外で動くときは、従来どおり何も登録しません。
- playback runtime は約 16.5 KB（gzip で約 7 KB）大きくなります。経緯は [ブロックパレットの統合](../design/dsl-4-block-palette-unification.md) の §13 を参照してください。

## 互換性

再生時の動作は変わりません。4.0.27 までに作った SB3 は、それぞれに同梱されたランタイムで従来どおり動きます。
