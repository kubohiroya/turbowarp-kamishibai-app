# 4.0.27 — 旧形式の台本ブロックを移す移行コマンドと、旧拡張の明示

- `migrate-block-palette` を加えました（#1214）。4.0.25 より前に保存した作品の台本ブロックを、「紙芝居の台本ブロック」拡張の opcode から runtime の opcode へ書き換え、その拡張を作品から外します。変換の前後でブロックから読んだ台本・素材・target のデータが同じことを確かめ、入力は変えず、出力を上書きしません。統合前の runtime は現行のものに差し替えます。`--restore` で元の形に戻せます。
- `migrate-embedded-yaml` も、統合後の runtime に差し替えるときは同じ変換で旧拡張を外します。
- 以前の「紙芝居の台本ブロック」拡張を旧形式と明示しました。名前は `Kamishibai Block Script (legacy)`（パレットでは「紙芝居の台本ブロック（旧形式）」）になり、拡張ファイル先頭の説明で `migrate-block-palette` を案内します。この拡張は、古い runtime を土台にした作品の作成で引き続き書き出します。
- 組込 YAML の表示用に残っていた旧拡張の変種と、その生成物を撤去しました。カタログに載る旧拡張の変種は8種類になります。
- 経緯は [ブロックパレットの統合](../design/dsl-4-block-palette-unification.md) の §11・§12 を参照してください。

## 互換性

- 4.0.25 より前に保存した作品は、同梱している旧拡張でそのまま開けます。パレットに出る名前だけが「（旧形式）」付きになります。
- 移行コマンドの失敗は `K4-MIGRATION-PALETTE-*` のコードで報告します。
