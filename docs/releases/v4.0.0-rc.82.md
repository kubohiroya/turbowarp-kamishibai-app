# 4.0.0-rc.82 — 上流パッケージの最新公開版への更新

関連: [App #1131](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/1131)。DSLは`4.0`、Camera Sourceは`0.22.1`を維持する。公開済みrc.81以前のmetadata・tag・配布物は変更しない。

## 変更範囲

依存する`@kubohiroya/*`パッケージを、npmの`latest`にある最新公開版へ揃える。作品の書式・CLIの振る舞いは変えない。

| パッケージ                                | rc.81      | rc.82      |
| ----------------------------------------- | ---------- | ---------- |
| turbowarp-asset-cache                     | 0.6.0      | 0.6.1      |
| turbowarp-extension-loader                | 0.5.0      | 0.8.0      |
| turbowarp-sb3-save-format                 | 0.4.0-rc.0 | 0.4.0-rc.2 |
| turbowarp-document-source                 | 0.1.0-rc.0 | 0.2.0-rc.0 |
| turbowarp-document-data                   | 0.5.0-rc.1 | 0.6.0-rc.0 |
| turbowarp-yaml-json                       | 0.8.0-rc.0 | 0.9.0-rc.0 |
| vite-plugin-turbowarp-extension（開発用） | 0.10.0     | 0.11.0     |

document-source 0.2は実装の再exportを外し、共通契約だけを持つパッケージになった。App側のimportは同パッケージの「Migrating from 0.1」の対応表に従って移す。契約（参照の符号化・読取、型、source記述の正規化）は`document-source`から、レジストリ・hat・marker・取得は`document-data/document-source`から、`project-views`・`view-metadata`は`document-data`から、`yaml-blocks`・`source-view`は`yaml-json`から読む。参照文字列・opcode・保存形式・共有レジストリのsymbolは変わらない。

[rc.77](v4.0.0-rc.77.md)で入れたAsset Cache 0.6.0向けの隔離patchは、Asset Cache 0.6.1に同じ修正が入ったため削除する。rc.81の課題として残していた`@kubohiroya/turbowarp-document-source`のgit pin参照は、npm公開版の利用で解消した。

[rc.81](v4.0.0-rc.81.md)の保存形式の指定とremoteアセットの保持コピー、[rc.80](v4.0.0-rc.80.md)の共通データソース契約、[rc.79](v4.0.0-rc.79.md)のタイトルカメラ判定、[rc.78](v4.0.0-rc.78.md)の依存初期化と作品読込後の再接続、[rc.77](v4.0.0-rc.77.md)の既定OFFプレビューを維持する。

## 検証・公開・切戻し

型検査・lint・`test:full`（全2388件）で、release pin・runtime provenance・DSL 4.0 core graphの依存境界・composition graphの監査を確認する。同梱するDSL 4.0 runtime拡張3件は新しい依存から再生成した。Extension Loaderは0.5.0から0.8.0へ上がるが、実ブラウザでの再生確認（Plusホスト・標準TurboWarpとも）は本候補の凍結後に行う。

公式driverによるrc.82の生成・凍結と公開後のhash照合を分け、候補の存在だけで公開完了を主張しない。

切戻しは公開済みのrc.81 SB3・npm版へ戻す。既存版を上書きせず、修正が必要なら次のrcを作成する。
