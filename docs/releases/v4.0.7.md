# 4.0.7 — 停止ボタンで作品を止め、緑の旗でタイトルに戻す

4.0.7 は、再生中の作品を止める経路の修正だけが入っています。台本、保存データ、作品の保存形式、ブロックは変わりません。

## 止まらなかった再生

終わりのメニューの「もう一度見る」から再生し直した作品は、赤い停止ボタンを押しても止まらず、そのまま最後まで動き続けました。続けて緑の旗を押しても、前の再生が片付かず、タイトル画面にも戻りませんでした。同じことが、編集画面で台本を開いて始めた再生と、再生設定で計算方式を変えて始め直した再生でも起きていました。タイトル画面から始めた最初の再生だけは、どちらのボタンも効いていました。

拡張は、起動・停止・作り直しを一つずつ順に実行する待ち行列で直列化しています。停止ボタンは VM の `PROJECT_STOP_ALL` を受けて片付けをこの待ち行列に積み、緑の旗はタイトルの作り直しを積みます。上に挙げた経路は、作品の再生そのものをこの待ち行列の中で待っていたため、再生が自分で終わるまで、後ろに積まれた停止と作り直しの順番が来ませんでした。タイトルから始めた再生だけは、もともと待ち行列の外で始まっていました。

4.0.7 では、再生の開始を待ち行列の外へ出しました（`scripts/sb3/dsl4-runtime-extension-entry.ts` の `startStoryOutsideOperations`）。再生を始める処理のうち、状態の公開とタイトルの片付けは同じ同期の実行で終わるため、呼び出し側はこれまでどおり「再生が始まった」状態を見ます。待ち行列に残るのは起動と片付けだけになり、停止ボタンと緑の旗はどの経路から始めた再生に対しても、すぐに順番が来ます。

回帰は `test/e2e/dsl4-runtime-stop-chromium.test.ts` が持ちます。公開した作品を Player として実際に動かし、最初の再生と「もう一度見る」の再生の両方で、停止ボタンが作品を止め、続く緑の旗がタイトルを出すところまでを確かめます。

### 変わらないもの

- 停止と緑の旗が行う片付けの中身は変わりません。
- 待ち行列そのものは残ります。起動・停止・作り直しは、これまでどおり一つずつ順に実行します。

## 切り戻し

4.0.6 の npm パッケージ、Standard SB3、Player に戻してください。台本や保存データの変換は不要です。
