# 4.0.0-rc.84 — asset ブロックの素材プレビュー

関連する変更は [Issue #1132](https://github.com/kubohiroya/turbowarp-kamishibai-app/issues/1132) と [PR #1133](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/1133) にまとめる。

## 変更範囲

- asset ブロックの設定フォームに画像・音声・動画のプレビューを併設する。未保存の素材指定を反映する。
- 画像・動画の寸法とファイルサイズ、素材の保持形態を表示する。コスチュームと画像の透過部分には市松模様が見え、ホバー中は緑の1px枠が出る。
- Web 素材を非同期に取得し、取得に失敗したときは検証済みの保持コピーがあれば表示する。
- [rc.82](v4.0.0-rc.82.md) で取り込んだ上流パッケージの更新と、document-source 0.2 の共通契約を含む。

rc.83 の検証で確認した配布用 SB3 のサイズ超過に対応し、タイトル画面に同梱する公式サイトアイコンを表示用途に合う128px版へ変更した。

## 検証・公開・切り戻し

Chrome の TurboWarp Plus Editor で、既定の素材表示、フォームの下書きへの追従、音声・動画の再生、画像の透過表示、素材の寸法とサイズ、遠隔取得と保持コピーへの切り替えを確認した。凍結済み SB3 は再ビルドで照合する。

公開状態は未公開。asset プレビューを無効にするには、Editor の起動 URL に `twPlusBlockPreview=0` を付けて再読み込みする。
