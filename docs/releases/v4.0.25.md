# 4.0.25 — 組み込みYAMLとシーンの参照を矢印で示せるようにする

- ランタイム拡張のブロック定義に、エディター向けの参照の宣言（`scriptRelations`）を加えました。「組み込みYAMLの起点」と「組み込みYAMLを取り込む」は、同じ文書を指す「組み込みYAML」ハットを参照します。TurboWarp Plus Editor（Code Views の対応版以降）は、これをほかの矢印と色・太さ・線種で区別された参照の矢印として描きます。
- 「シーン（scene）へ移る」と「現在のアクションからシーンへ移る」は、台本ブロックの同じ名前の「シーン」ブロックを参照します。矢印はスクリプトのハットではなく、スクリプト内のそのシーンのブロックを指します。
- 「キー入力で移る」「登場人物へのタッチで移る」「ポーズで移る」「画像のラベルで移る」は、行き先（ROUTES の JSON）に書かれた各シーンを参照します。矢印は入力ごとに描かれ、ラベルは「入力 → シーン」です。
- 宣言は opcode ではなく名前のチャンネル（`kubohiroya.kamishibai4.embeddedYamlDocument`、`kubohiroya.kamishibai4.scene`）で結ぶため、バンドル版とバンドルしない版のどちらでも、ランタイムと台本ブロックの拡張をまたいでも同じように働きます。

## 互換性

宣言はエディターだけが読む情報で、TurboWarp と再生時の動作は変わりません。対応していないエディターでは何も表示されません。4.0.24 までに作った SB3 は、それぞれに同梱されたランタイムで従来どおり動きます。

## 受け入れ基準と切り戻し

凍結 SB3 の再ビルドによる照合とリリース検証が通過してから公開します。旧版を使用する場合は npm で `4.0.24` を明示します。
