# 4.0.25 — 台本ブロックと命令ブロックを1つのパレットにまとめる

- 台本ブロック（シーン、素材・登場人物などの定義、作品の設定、ポーズの手順、もし・くりかえす、条件と値など）を runtime 拡張が定義するようにしました。これまで別の拡張「紙芝居の台本ブロック」に分かれていたブロックが、命令ブロックと同じパレット「紙芝居」に並びます。
- パレットのグループを作者の作業順に並べ直しました。台本の骨組み、素材と登場人物、作品の設定、舞台、音、音声・動画、セリフと文字、登場人物の表示、進行、条件と値、入力で移動、ポーズ、台本の変数、進行の状態、詳しい指定、開発・診断、YAMLの部品の順です。ポーズの手順は `pose` と、もし・くりかえすは `goto`・分岐と、組込 YAML の文書ハットはシーンと同じグループに入ります。
- `author-block-dsl` と組込 YAML のブロック表示は、土台の runtime が統合後の版なら台本ブロックを runtime の opcode で書き、別の拡張を同梱しません。古い runtime を土台にした場合は、従来どおり「紙芝居の台本ブロック」拡張を同梱します。
- 「この部分を使う」ブロックは、作品に既にあるときだけパレットに表示します。
- 経緯と決めたことは [ブロックパレットの統合](../design/dsl-4-block-palette-unification.md) を参照してください。

## 互換性

- 以前に保存した作品は、同梱している「紙芝居の台本ブロック」拡張でそのまま開けます。runtime は旧拡張・runtime 単体・Standard bundle のどの opcode で書かれた台本ブロックも同じ台本として読みます。
- パレットのグループ ID が変わったものは、TurboWarp Plus の表示・非表示の設定が初期状態に戻ります。
- 拡張ファイル先頭の名前（`Kamishibai DSL 4.0 Runtime`）は変えていません。パレット上の表示名だけが「紙芝居」（英語 `Kamishibai`）になります。
