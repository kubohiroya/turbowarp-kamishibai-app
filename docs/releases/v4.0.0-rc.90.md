# 4.0.0-rc.90 — 台本ブロック用拡張の名前と作者

## 変更範囲

台本ブロック用拡張のソースに TurboWarp 形式の見出しを付けました。TurboWarp Plus Editor でこの拡張を含む作品を開くと、機能拡張の確認画面に「Kamishibai Block Script」と作者名が表示されます。ブロック SB3 の生成と組み込み YAML からの移行にも適用します。

## 切り戻し

前回の公開版 `4.0.0-rc.89` の npm パッケージ、Standard SB3、Player を使用してください。台本の DSL と保存形式は変わりません。
