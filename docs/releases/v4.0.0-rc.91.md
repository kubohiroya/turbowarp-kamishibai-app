# 4.0.0-rc.91 — 設定パネルと Dock のテーマ対応

## 変更範囲

カメラ選択と Teachable Machine の設定パネル、Runtime controls の Dock が、Editor のテーマ（ライト・ダーク・自動）に合わせて表示されるようになりました。パネルの閉じるボタンは「Close」の文字ではなく X アイコンになりました。あわせて `@kubohiroya/turbowarp-app-shell` を 0.6.1 に、`@kubohiroya/turbowarp-camera-source` を 0.23.1 に上げました。

## 切り戻し

前回の公開版 `4.0.0-rc.90` の npm パッケージ、Standard SB3、Player を使用してください。台本の DSL と保存形式は変わりません。
