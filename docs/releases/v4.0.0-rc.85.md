# 4.0.0-rc.85 — Standard SB3 の WASM 同梱サイズ削減

関連する変更は [Issue #1134](https://github.com/kubohiroya/turbowarp-kamishibai-app/issues/1134)、[PR #1135](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/1135)、[PR #1136](https://github.com/kubohiroya/turbowarp-kamishibai-app/pull/1136) にまとめる。

## 変更範囲

- Standard SB3 は Teachable Machine の SIMD 版とスレッド付き SIMD 版の WASM を圧縮して同梱し、初回利用時に復元する。通常版の WASM は同梱しない。
- SIMD 非対応の環境で WASM を明示指定すると JavaScript CPU に切り替える。自動選択では WebGPU と WebGL を先に試す。
- 公式 TurboWarp Editor で測定した単一スレッド SIMD、スレッド付き SIMD、WebGPU のポーズ推論時間を [サイズ監査](../design/dsl-4-standard-sb3-size-audit.md) に記録した。
- [rc.84](v4.0.0-rc.84.md) の素材プレビューと、[rc.82](v4.0.0-rc.82.md) の上流パッケージ更新を含む。

## 凍結済み SB3 の検証

SB3 は7,801,127バイト。展開後の `project.json` は15,135,495バイトで、16 MiBの上限まで1,641,721バイトの余裕がある。通常版の WASM のバイナリが含まれないことを確認し、SIMD の2本を展開して npm 配布物とバイト単位で照合した。

通常テスト2,391件とプレビューのテスト59件が成功した。Chromium E2E は26件中25件が成功し、Asset Cache の1件は rc.84 と同じ箇所でタイムアウトした。

## 公開・切り戻し

公開状態は未公開。従来の WASM 構成に戻す場合は、`dsl4ReleaseCompactWasm` を OFF にして新しい候補版を生成する。旧SB3を読み込んだ Editor タブで rc.85 を使う場合は、Editor を再読み込みしてから開く。
