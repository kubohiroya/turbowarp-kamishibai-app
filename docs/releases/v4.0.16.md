# 4.0.16 — 人物のアニメーションと舞台演出をローカルで試す

未公開候補です。台本の宣言は `kamishibai: '4.0'` のままです。

`<actor>.animate` は位置・サイズ・向き・透明度を一つの時間軸で動かせます。
`presentationEffect` はステージまたは物語の演出レイヤーに揺れ・ズーム・ワイプ・フェードを適用します。
ローカルプレビューの `--enable-presentation-effects` を指定したときだけ実行します。
既存の4.0台本、カスタムアクション、標準の配布用SB3の動作は変更しません。
詳しい引数と競合・終了時の扱いは[アニメーションと演出](../design/dsl-4-presentation-effects.md)を参照してください。

確認済みのプレビューでは、実VMで人物の座標・サイズ・向き・透明度が指定値になり、
Chromium上で舞台の揺れと、終了時に演出が残らないことを確認しました。
同じ台本の通常の `build-dsl4` は、未対応の配布用SB3を作らず明示的に拒否します。

公開のためのタグ、npm登録、GitHub Release、Pagesは今回の作業では変更しません。
