# 4.0.23 — ステージのスクリプトを整理

- 生成される SB3 のステージのスクリプトを「緑の旗 → タイトル画面を表示」と「ステージが押されたとき → タイトル画面を閉じる」の2本にしました。ステージクリックと閉じるボタンは、`closeTitle` メッセージの送受信を経由せず、同じ「タイトル画面を閉じる」を直接実行します。
- どこにも接続されていなかった「内部の文字 about.version を …」ブロックを生成しなくなりました。版とビルド日はタイトル背景の SVG に刻まれた表示から読み取ります。4.0.22 までの凍結済み SB3 は、従来どおりブロックから読み取ります。

## 互換性

4.0.22 までに作った SB3 は、それぞれに同梱されたランタイムで従来どおり動きます。古いステージのスクリプト（`closeTitle` の送受信）が新しいランタイムに読み込まれても、タイトル画面は閉じられます。

## 受け入れ基準と切り戻し

凍結 SB3 の再ビルドによる照合とリリース検証が通過してから公開します。旧版を使用する場合は npm で `4.0.22` を明示します。
