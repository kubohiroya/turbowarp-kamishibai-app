# 4.0.20 — 台詞・字幕で台本変数を使う

ブロック台本の台詞・心の声・字幕で、定数・「つなげる」・「台本の変数」を組み合わせられます。
式は保存・YAML書き出しで保持され、上演中にその命令を実行したときに一度だけ評価します。
既存の固定文・ルビと、DSL宣言 `kamishibai: '4.0'` はそのままです。任意のScratch処理は実行しません。

[4.0.17](v4.0.17.md) の無効区間専用モデルの先読み抑止を含みます。
