# 4.0.35 — 紙芝居のブロックグループを8つにまとめる

- TurboWarp Plus Editor のパレットに並ぶ紙芝居のブロックグループを17から8にまとめました。
  - 台本の骨組み（骨組み、YAMLの部品、詳しい指定）
  - 素材と設定（素材と登場人物、作品の設定）
  - 舞台と音（舞台、音、音声・動画）
  - 登場人物とセリフ（登場人物の表示、セリフと文字）
  - 進行（進行、条件と値、入力で移動）
  - ポーズ
  - 変数と状態（台本の変数、進行の状態）
  - 開発・診断
- 詳しくは [ブロックパレットの統合 §16](../design/dsl-4-block-palette-unification.md) を参照してください。

## 互換性

ブロックの opcode、台本の書式、セーブデータの形式（SaveDataV1）は変わりません。Scratch と TurboWarp では従来どおり1つのカテゴリに表示されます。まとめたグループは先頭のグループの ID を引き継ぐため、Editor で表示の設定を保存した作品ではそのグループは表示されたままです。なくなった ID（`settings`、`sound`、`media`、`speech`、`values`、`input`、`status`、`details`、`document`）だけを表示していた作品では、そのブロックが入ったグループを表示し直してください。4.0.34 までに作った SB3 は、それぞれに同梱されたランタイムで従来どおり動きます。
