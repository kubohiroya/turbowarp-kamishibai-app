# 4.0.35 — 編集用 SB3 で場面・動作のプレビューを出す

- `migrate-embedded-yaml` が書き出す編集用のブロック SB3 に、playback 用ではなく authoring 用の runtime を積むようにしました。場面・動作・素材のプレビューを登録するのは authoring 用の runtime だけなので、これまでは TurboWarp Plus Editor がプレビューを既定で有効にしていても、編集用 SB3 ではプレビューが出ませんでした。
- narrative の有無にかかわらず同じ authoring 用の runtime を積みます。編集用 SB3 は約 0.5 MB 大きくなります。
- 詳しくは [ブロックのアイコンからのプレビュー](../design/dsl-4-block-icon-preview.md) の「導入と切戻し」を参照してください（PR #1224）。

## 互換性

台本の書式、保存データの形式、配布用 SB3 に積む runtime は変わりません。4.0.34 までに作った編集用 SB3 は、同梱された runtime のまま従来どおり開けます。プレビューを出すには、4.0.35 の `migrate-embedded-yaml` で変換し直します。

## 受け入れ基準と切り戻し

凍結 SB3 の再ビルドによる照合、リリース検証、配布用 CLI の動作確認が通過してから公開します。
旧版を使用する場合は npm で `4.0.33` を明示します。
