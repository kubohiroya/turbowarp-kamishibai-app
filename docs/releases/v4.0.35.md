# 4.0.35 — BGM・場面の音声・text・loop をセーブポイントから戻す

- セーブポイントに、action の後も残る次の作用を保存し、復元で元に戻します。
  - BGM：保存時の BGM を、fade 中なら向かう先の音量で、最初から鳴らし直します。再生位置は保持しません。
  - 場面の音声（`audio`・`audioControl`）：再生位置・一時停止・loop・音量・muted・速度を保持し、再生中だったものだけを再開します。
  - `setText`：俳優ごとの text と style を保持し、描き直します。後から skin を貼った俳優の text は記録から外します。
  - `loop`：俳優ごとの steps を保持し、最初の段から再開します。
- これまでは `bgm`・`audio`・`audioControl`・`setText`・`loop`・`sound` を持つ `pose` を1つでも実行した作品は、セーブ自体ができませんでした。TurboWarp 上の再生ではこれらの後でもセーブできます。`sound` を持つ `pose` の段の音は一度だけ鳴る音として扱い、復元では止めて再開しません。
- 復元のとき、crossfade で鳴っていた BGM が止まらずに残る不具合を直しました。保存時に BGM が無ければ止めます。
- `broadcastMessageAndWait` と custom action は Scratch の変数やリストを含む任意の状態を変えるため、これらを履歴に持つセーブは引き続き拒否します。
- 詳しくは [セーブと viewport](../design/dsl-4-save-viewport.md) の「表示の復元範囲」を参照してください。

## 互換性

台本の書式は変わりません。セーブデータの形式（SaveDataV1）の版は変わらず、表示の部分に `media` を加えます。4.0.34 までに保存したセーブは、BGM・音声・text・loop の無い状態としてそのまま復元できます。4.0.35 で保存したセーブを 4.0.34 以前で読み込むと、未知の表示の項目として拒否します。4.0.34 までに作った SB3 は、それぞれに同梱されたランタイムで従来どおり動きます。
