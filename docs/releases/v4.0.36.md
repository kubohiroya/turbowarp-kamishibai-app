# 4.0.36 — 登場人物をアニメーションさせるブロックの指定 JSON をフォームで編集する

- 「登場人物 [TARGET] をアニメーションさせる 指定 JSON [SPEC]」の `SPEC` を、ブロックエディターのフォームで編集できるようにしました。これまでフォームが出るのは「言う」「考える」の指定だけで、アニメーションの指定は JSON の文字列を手で書く必要がありました。
- フォームは DSL 4.0 の正典スキーマ（`animateArgs`）から作ります。変化させる値（x座標・y座標・大きさ・向き・透明度）、秒数、動き方、開始までの秒数、繰り返す回数、往復する、終わりを待たずに次へ進む、の各欄を日本語の名前で表示します。スキーマに合わない値はフォームで確定できません。

## 互換性

台本の書式、ブロックの opcode と引数、セーブデータの形式（SaveDataV1）は変わりません。保存済みの `SPEC` の文字列はそのまま読み込まれ、フォームで変えたときだけ書き換わります。4.0.35 までに作った SB3 は、それぞれに同梱されたランタイムで従来どおり動きます。
