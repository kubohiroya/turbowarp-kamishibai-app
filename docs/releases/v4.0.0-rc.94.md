# 4.0.0-rc.94 — 吹き出しのルビ

## 変更範囲

`Actor.say`と`Actor.think`の`text`に、`Actor.setText`と同じ書き方でルビを付けられるようになりました。

```yaml
- Hero.say:
    text:
      - 昔、
      - ruby: {base: 浦島, reading: うらしま}
      - 太郎がいました。
    waitFor: advance
```

読みは本文（base）の上に表示されます。1文字ずつの表示（`characterIntervalSeconds`）や吹き出し自身の段階表示（`bubbleReveal`）では、本文と読みを1つの単位としてまとめて出すので、読みだけが先に見えたり本文の途中で止まったりしません。ルビを含まない台本の表示は変わりません。

あわせて `@kubohiroya/turbowarp-bubble` を 0.19.0 に、`@kubohiroya/turbowarp-svg-text` を 0.15.0 に上げました。どちらもブラウザーでの吹き出し（SVG overlay）でルビを描くための版です。

## 切り戻し

前回の公開版 `4.0.0-rc.93` の npm パッケージ、Standard SB3、Player を使用してください。ルビを書いた吹き出しは rc.93 では読み込めないので、文字列に戻してください。台本の DSL と保存形式はそれ以外は変わりません。
